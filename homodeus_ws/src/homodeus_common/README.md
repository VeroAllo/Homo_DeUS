# Homo DeUS Common
Ici, se trouve les éléments communs à Homo DeUS

## Dossiers
- [homodeus_library](homodeus_library) contient des constantes et des signatures de fonction en Python utilisées au travers les autres modules.
- [homodeus_msgs](homodeus_msgs) contient les types de messages ROS construits pour le projet Homo DeUS
- [homodeus_parameters](homodeus_parameters) contient des configurations ROS spécifiques pour le robot TIAGo
- [maps](maps) contient les cartes (*maps*), cartes d'occupation 2D, utilisées en simulation
- [worlds](worlds) contient les mondes (*worlds*) Gazebo pour développer en simulation
